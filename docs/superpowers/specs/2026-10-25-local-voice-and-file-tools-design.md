# GlassChat — локальный голос, скрытые инструменты и инструменты файлов/терминала

Дата: 2026-10-25. Статус: дизайн одобрен в чате, спецификация на ревью.
Продолжает `2026-10-24-notch-assistant-design.md` (ветка `feature/notch-assistant`).

## Цель

1. Промпт ассистента в настройках — настоящий редактируемый текст, адаптированный под «ответ голосом на каждый запрос».
2. Голос ассистента — локальная модель Supertonic 3; голос macOS — запасной.
3. Служебные встроенные инструменты получают префикс `_` и, как любые инструменты с `_` (включая MCP), не передаются модели, но находятся через `search_tools`.
4. Новые инструменты `app_read`, `app_write`, `app_edit`, `app_bash`, с режимами подтверждения.
5. Распознавание речи — два режима: Apple или локальный whisper-large-v3-turbo (WhisperKit); обе модели (Whisper и Supertonic) скачиваются шагом первого запуска.

## Зависимости (проверено пробной сборкой с CLT и SDK 26.5)

- `argmaxinc/WhisperKit` **0.18.0** (точная версия), продукт `WhisperKit`.
- `onethreeeseven/supertonic.swift` по ревизии **e26051d3** (у репозитория нет тегов версий), продукт `Supertonic`; тянет ONNX Runtime 1.24.2 (бинарный артефакт, ~52 МБ).
- `apple/swift-collections` закреплён **`"1.1.0"..<"1.3.0"`** (собралось с 1.2.1): 1.7.x требует типов стандартной библиотеки из SDK 27 (`Span.BorrowingIterator`) и не собирается с SDK 26.5.
- Это первые удалённые зависимости проекта (остальные — в `Vendor/`). `Package.resolved` коммитится.

## 1. Промпт ассистента

- `AppSettings.assistantPrompt` хранит сам текст; при первом запуске новой версии пустое значение заменяется на `AssistantPrompt.standard`. «Reset» записывает в поле стандартный текст. `AssistantPrompt.effective` остаётся (пустая строка → стандартный).
- Новый `AssistantPrompt.standard` (английский, отвечать на языке пользователя):
  - ассистент в ноче MacBook, речь распознана автоматически и может содержать ошибки;
  - **на каждый запрос** вызвать `glasschat__app_say` с одной короткой репликой, как ответил бы человек: выполнено действие — «Готово, выключил omnixon»; вопрос — самый короткий ответ по сути;
  - текстом — кратко, но чуть подробнее голосовой реплики (1–3 предложения или короткий список);
  - уточнять через `glasschat__app_ask_user`, когда есть понятные варианты;
  - служебные инструменты (чаты, модели, MCP-реестр, файлы, терминал) искать через `glasschat__search_tools`.

## 2. Голос — Supertonic 3

- `Speaker` синтезирует речь через `Supertonic.synthesize(text, in: language, voice:)` и проигрывает `samples` (44,1 кГц) через `AVAudioEngine`/`AVAudioPlayerNode`; уровень для аватара — RMS буферов, как сейчас.
- Язык — по тексту (`SpeechText.language`) → `Language(languageCode:)`; неизвестный → `na`.
- Голос — настройка «Voice» со списком `Voice.allCases` (10 голосов), по умолчанию первый женский.
- Запасной путь — `AVSpeechSynthesizer` (текущий код с выбором голоса по языку): пока модель не скачана, или если синтез бросил ошибку.
- Убираются: роль `ModelRole.speech`, настройки TTS-модели/голоса провайдера, `OpenAIClient.speech`, выбор голоса macOS в настройках (голос macOS выбирается по языку текста автоматически).

## 3. Скрытые инструменты (`_`)

- Переименование (имя функции = `glasschat__` + новое имя): `_mcp_registry_delete`, `_mcp_registry_update`, `_mcp_registry_add`, `_mcp_registry_get`, `_mcp_registry_list`, `_app_list_mcp`, `_app_enable_mcp`, `_app_disable_mcp`, `_app_list_models`, `_app_set_model`, `_app_list_chats`, `_app_create_chat`, `_app_switch_chat`, `_app_rename_chat`, `_app_delete_chat`.
- Правило: функция, чьё имя инструмента (часть после `server__`) начинается с `_`, не входит в список инструментов запроса, если её не нашёл `search_tools` в этом ответе. Это касается и инструментов MCP-серверов.
- `search_tools` ищет среди всех инструментов, включая скрытые (как сейчас — среди выключенных); найденные доступны до конца ответа.
- Отображение (`ToolCallCard`, `MCPSettings`) показывает имя как есть, с `_`.

## 4. Инструменты файлов и терминала

Все — встроенные `AppTool`, группа `AppTool.key`, видимые (без `_`).

- **`app_read(path, offset?, limit?)`**:
  - путь абсолютный или с `~`; относительный — от рабочей папки чата (см. bash);
  - файл: строки с номерами в формате `cat -n` (`%6d\t`), с `offset` (1-based строка) и `limit` (по умолчанию 2000); строки длиннее 2000 символов обрезаются; бинарный файл (есть NUL в первых 8 КБ) — ошибка «binary file»;
  - директория: отсортированный список имён, папки с `/` на конце, скрытые файлы включены; не больше 1000 записей (дальше «… and N more»).
- **`app_write(path, content)`**: создаёт недостающие папки, перезаписывает файл; результат — «Wrote N bytes to path».
- **`app_edit(path, old_string, new_string, replace_all?)`**: точное совпадение; нет совпадений — ошибка; несколько без `replace_all` — ошибка с числом совпадений; `old_string == new_string` — ошибка; результат — число замен.
- **`app_bash(command, timeout?)`**:
  - `/bin/zsh -l -c` с рабочей папкой чата; рабочая папка запоминается: после команды выполняется `pwd` в той же оболочке (через разделитель), и новая папка сохраняется для чата; начальная — домашняя;
  - тайм-аут по умолчанию 120 с, максимум 600 с; по тайм-ауту процесс убивается (SIGTERM, затем SIGKILL через 2 с), результат — «Timed out after N s» и вывод до этого;
  - вывод stdout+stderr, обрезка до 30 000 символов (с пометкой), в конце «Exit code: N»;
  - отмена ответа убивает процесс.
- **Подтверждение** (`app_write`, `app_edit`, `app_bash`; `app_read` — без подтверждения). Настройка «Tools → Confirm actions»:
  - **Auto** (по умолчанию): decision-модель (Jev) через `/alpha/decisions` выбирает между вариантами «safe» и «dangerous» по описанию действия (инструмент, путь/команда, папка). Выполняется сразу, если вероятность «safe» ≥ 0,5; иначе — красная карточка подтверждения. Нет decision-модели или ошибка запроса — карточка.
  - **Always ask**: карточка на каждое действие.
  - **Never ask**: выполнять сразу.
  - Карточка (`ActionApprovalCard`, в чате и в ноче — как `QuestionCard`): красный заголовок для «dangerous» / обычный для Always ask, команда или путь (для edit — фрагменты old/new), кнопки «Allow», «Allow in This Chat» (до конца жизни чата в этой сессии для этого инструмента), «Deny». Deny → результат инструмента `"The user denied this action."` (ошибка). Stop ответа → отклонение.
  - Предупреждение в настройках: в Auto решение принимает модель; текст из файлов или сайтов может на неё повлиять.

## 5. Распознавание — Apple или Whisper

- `RecognitionMode`: `builtIn` (Apple, как сейчас, несколько языков) и `whisper` (WhisperKit, вариант модели `large-v3-v20240930_turbo` — whisper-large-v3-turbo; не меняется).
- Перенос: `localWhisper` → `whisper`; `provider`, `audioToModel` → `builtIn`.
- Убираются: `RecognitionMode.provider/.audioToModel`, роль `ModelRole.transcription`, `OpenAIClient.transcribe`, `MultipartForm` (если больше не используется), `LocalWhisper` (whisper.cpp/brew/whisper-server).
- `WhisperTranscription`: Apple показывает живой текст, финальный текст — `WhisperKit.transcribe(audioPath:)` (язык — автоопределение); при ошибке — текст Apple (как `FinalTranscription`).
- `WhisperKit` загружается один раз и держится в памяти (`VoiceModels`), прогревается при раскрытии ноча.

## 6. Загрузка моделей

- `VoiceModels` (`@Observable @MainActor`): состояние каждой модели — `missing`, `downloading(fraction)`, `ready`, `failed(message)`; `downloadAll()` качает Whisper (`WhisperKit.download(variant:progressCallback:)`) и Supertonic (`ModelAssets.download(progress:)`) в `~/Library/Application Support/GlassChat/models/`.
- Первый запуск: третий шаг онбординга «Voice models» — прогресс обеих моделей, кнопка «Continue» доступна сразу (загрузка продолжается в фоне).
- Если модели не скачаны (например, онбординг был пройден в прошлой версии) — загрузка стартует сама при запуске приложения.
- Settings → Assistant: статус обеих моделей и «Download again» при ошибке.
- Пока Whisper не готов, режим `whisper` распознаёт через Apple; пока Supertonic не готов — голос macOS.

## Проверка

Встроенный self-test (DEBUG):
- скрытие `_`: функция скрыта без поиска, видна после поиска, правило для MCP-имён;
- `app_read`: нумерация строк, offset/limit, обрезка длинных строк, бинарный файл, листинг директории (папки с `/`, лимит);
- `app_edit`: одна замена, «нет совпадений», «N совпадений без replace_all», replace_all;
- `app_bash`: вывод и код выхода, сохранение рабочей папки после `cd`, тайм-аут, обрезка вывода;
- решение подтверждения: режимы × ответ Jev × нет decision-модели;
- перенос `RecognitionMode` и промпта;
- выбор языка Supertonic по тексту.

Запуском приложения: загрузка моделей в онбординге, голос Supertonic (русский/английский), Whisper через WhisperKit, карточка подтверждения в чате и ноче.
